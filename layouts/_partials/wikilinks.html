{{- $page := .Page -}} {{- $raw := .RawContent -}} {{- $re := `\[\[([^\]\|]+?)(?:\|([^\]]+?))?\]\]` -}} {{- range findRESubmatch $re $raw -}} {{- $full := index . 0 -}} {{- $target := trim (index . 1) " " -}} {{- $label := "" -}} {{- if ge (len .) 3 -}} {{- $label = trim (index . 2) " " -}} {{- end -}} {{- $found := false -}} {{- $href := "" -}} {{- $text := cond (ne $label "") $label $target -}} {{- range $page.Site.RegularPages -}} {{- $title := trim (.Title | plainify) " " -}} {{- $linkTitle := trim (.LinkTitle | plainify) " " -}} {{- $base := "" -}} {{- with .File -}} {{- $base = .BaseFileName -}} {{- end -}} {{- $baseNoExt := replaceRE `\.[^.]+$` "" $base -}} {{- if and (not $found) (or (eq $target $title) (eq $target $linkTitle) (eq $target $base) (eq $target $baseNoExt)) -}} {{- $href = .RelPermalink -}} {{- if eq $label "" -}} {{- $text = .Title -}} {{- end -}} {{- $found = true -}} {{- end -}} {{- end -}} {{- if ne $href "" -}} {{- $link := printf `%s` $href ($text | markdownify) -}} {{- $raw = replace $raw $full $link -}} {{- else -}} {{- $missing := printf `%s` ($text | markdownify) -}} {{- $raw = replace $raw $full $missing -}} {{- end -}} {{- end -}} {{- $raw | markdownify -}}
