# Wikilinks

Wikilinks are the main feature of Zettmin.

To create a wikilink, write for example `\[[Note_Title\]]`.

Zettmin also supports these wikilink formats:
- `\[[Note_Title|Display Title\]]`
- `\[[path/to/file\]]`

For example:
i love [[spaghetti]]
